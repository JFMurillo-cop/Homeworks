# Homeworks

## 🛍️ Proyecto final: CampusMarket

Tienda en línea del campus universitario hecha en **Angular + Firebase**: catálogo con buscador
inteligente, carrito de compras, pedidos con entrega por la ruta más corta, seguimiento de pedidos
y chat de soporte en tiempo real, con panel de administración.
