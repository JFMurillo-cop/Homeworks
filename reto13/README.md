# Challenge 13 · Buscador de GIFs (GIPHY)

React + Vite + TypeScript. Usa `fetch` con AbortController, debounce al escribir y paginación con "Cargar más".

## Cómo correrlo
1. Crea tu cuenta y una App (tipo API) en https://developers.giphy.com/ y copia tu API key.
2. Abre el archivo `.env` y pon tu clave: `VITE_GIPHY_API_KEY=tu_clave`
3. `npm install`
4. `npm run dev` y abre la dirección que muestra la terminal (normalmente http://localhost:5173).

El archivo `.env` está en `.gitignore`: no lo subas a GitHub.
